# Neovim Configuration
This repository contains my personal Neovim configuration. It’s tailored to my workflow, but feel free to explore, adapt, or use it as inspiration for your own setup.
Prerequisites

Neovim (version 0.8 or higher recommended)
Git (to clone this repository)

# Installation

Clone this repository to your Neovim configuration directory:
```shell
git clone git@github:ph-Wizz4/nvim-config-lazy.git ~/.config/nvim
```

> [!NOTE] 
> this config integrates with `lazy.nvim`


# Setup
## Required Variables
You need to set the following paths in your environment

```shell
OBSIDIAN_VAULT
JS_DEBUG_HOME
```
